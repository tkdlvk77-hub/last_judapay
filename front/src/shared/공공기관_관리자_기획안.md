# 공공기관 자금 집행 승인/결재 시스템 기획안 (참고용)
> 공공기관 로그인 화면 개발 시 반드시 참고할 것
> 현재 AdminManagement.jsx (결재라인/예산코드/증빙규칙/감사로그/에스컬레이션)는 공공기관 전용

---

## 핵심 구현 원칙
- 공공기관은 "빠른 송금"보다 "통제받는 집행" 구조
- 결재 없이는 돈이 못 나가는 구조
- 증빙 없이는 승인이 안 되는 구조
- 모든 행동이 감사 로그에 남는 구조

---

## 자금 집행 5단계 워크플로우 (미구현 → 공공기관 버전에서 구현 필요)

### STEP 1. 실무자 작성
- 거래처 선택, 계약 연결, 집행 금액, 예산 항목, 지급 목적
- 증빙 첨부: 계약서, 세금계산서, 견적서, 검수확인서, 지출결의서, 기타
- → 이 화면이 없음. 공공기관 버전에서 신규 제작 필요

### STEP 2. 팀장 승인 (1차)
- 예산 적합 여부, 금액 이상 여부, 증빙 누락 여부 검토
- 가능 액션: 승인 / 반려 / 수정 요청 / 추가 자료 요청

### STEP 3. 회계/재무 검토 (가장 중요)
- VAT 처리, 세금계산서 검증, 사업자 상태 확인, 예산 코드 확인
- 가능 액션: 승인 / 반려 / 보완 요청

### STEP 4. 최종 결재 (금액별 자동 라우팅)
- 50만원 이하 → 팀장 승인 종료
- 500만원 이하 → 부서장 승인
- 5,000만원 이상 → 국장 승인
- 1억원 이상 → 기관장 승인

### STEP 5. 자금 집행
- 최종 승인 후 자동 지급 실행
- 거래 기록 저장, 감사 로그 생성, 증빙 패키징

---

## 미구현 화면 목록 (공공기관 버전에서 신규 제작)
1. 집행 요청 생성 화면 (실무자 STEP 1)
2. 결재함 화면 (승인자 inbox — 가장 핵심)
3. 집행 요청 상세 화면 (단계별 상태 + 증빙 + 액션 버튼)
4. 금액 기반 자동 승인 라우팅 로직
5. 증빙 누락 시 다음 단계 차단 로직
6. 정산보고서 패키징 기능 (통합 증빙 센터에서)

---

## 현재 AdminManagement.jsx 구현 현황 (공공기관 설정 인프라)
- 결재라인 Builder (금액별/유형별/부서별)
- 구성원 관리 (7개 역할, 8개 권한, 결재 단계)
- 예산 코드 관리 (연간 예산 + 사용률)
- 증빙 규칙 설정 (유형별 필수/선택 서류)
- 감사 로그 (전체 집행 이력)
- 에스컬레이션 (미응답 자동 상향)
- 구성원 추가 3단계 플로우 (사람찾기 → 역할/부서 → 권한조정)

---

## 서류 관련 참고
- 거래명세서, 인건비 명세서, 정산보고서 → 통합 증빙 센터에서 자동 생성/다운로드
- 서버 연결 시 집행 완료 이벤트 기반으로 PDF 자동 생성
- 공공기관이 기업에 요구하는 제출 서류도 증빙 센터 패키징으로 커버 가능
